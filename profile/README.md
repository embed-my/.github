Embed interactive learning activities and documents on a website without installing any package or application.

**Embed My** creates an iframe snippet that teachers, instructional designers, and website owners can paste into a page they already manage. 
The first supported format is **H5P** (`.h5p`) packages. PDF embedding is planned.

## What it is for

Use Embed My when you have an H5P activity and want to show it on:

- a teaching portfolio;
- a school, course, or department website;
- a public resource page;
- a blog or documentation site;
- a CMS page that lets you paste an iframe but does not let you install an H5P plugin.

You do **not** need to install Moodle, WordPress, an H5P server, or a JavaScript package on the site where you paste the iframe.

## What you need

Before creating an embed, have:

1. An H5P package (`.h5p`) that you are entitled to share.
2. A public **HTTPS** URL for that file, for example:

   ```text
   https://courses.example.edu/activities/week-1-quiz.h5p
   ```

3. A page where you can paste HTML iframe markup, served over HTTPS.

The H5P file host must allow browsers to fetch the package from another origin (**CORS**). HTTP Range support is recommended for fast startup of large packages, but it is not required.

## Browser support

The activity runs inside the Embed My frame with a Service Worker of its own. That works in current Chrome, Edge, Firefox and Safari, on desktop and on Android, and on iOS from version 26. Older iOS versions have not been tested. The page containing the iframe must be served over HTTPS; on a plain `http://` page the frame has no Service Worker and nothing plays.

In-app browsers inside social and messaging apps sometimes give a frame no Service Worker at all. The frame then shows a link that opens the activity on its own Embed My page, which is also the fallback to offer wherever an iframe cannot be used.

## Create an H5P embed

1. Open [Embed My](https://embed-my.js.org/).
2. Choose **H5P package**.
3. Paste the direct public URL ending in `.h5p`.
4. Preview the activity.
5. Choose the display options you want: a title for the frame, and H5P's own toolbar under the activity with its **Rights of use** button, which shows the licences recorded in the package and its media, and a **Reuse** button that lets visitors download the package.
6. Copy the generated snippet.
7. Paste it into the HTML/embed block of your website and publish the page.

The generated code will follow this shape:

```html
<iframe
  src="https://embed-my.js.org/h5p?src=https%3A%2F%2Fcourses.example.edu%2Factivities%2Fweek-1-quiz.h5p"
  title="Week 1 knowledge check"
  loading="lazy"
  allow="fullscreen"
  style="width: 100%; min-height: 540px; border: 0"
></iframe>
<script src="https://embed-my.js.org/resizer.js"></script>
```

The script line is what lets the frame grow and shrink with the activity: the frame reports its height, and that script, included once per page, applies it. It is served by Embed My, so your page sends nothing to a third party. Without it the frame stays at the height in the `style` attribute and anything taller scrolls inside it. If your site strips scripts from pasted HTML, keep the iframe and give it a height that fits the activity instead. A page that already includes h5p.org's `h5p-resizer.js` for its h5p.org embeds needs no second script: it speaks the same protocol.

Use the exact code generated by Embed My. It may include additional parameters for a display option you selected.

## Example: publish an activity from a portfolio

If your package is available at:

```text
https://portfolio.example/learning/windows-shortcuts.h5p
```

create an embed for that URL, then paste the snippet into your portfolio's HTML/embed block. Visitors can complete the activity without an LMS account.

If your website cannot host the `.h5p` file itself, upload it to a host that provides a public HTTPS URL and CORS access first. Do not paste a link to a download page, a cloud-drive preview page, or a private LMS page; Embed My needs the URL of the `.h5p` file itself.

## H5P packages and library files

An H5P package normally includes the libraries it needs. Some exports contain only `content/` and expect an LMS or H5P.com to provide the libraries.

If the preview reports missing libraries:

- export the activity as a complete package, including libraries, when your authoring tool offers that option; or
- select a library source in Embed My if your organization provides one.

Do not assume that an activity which works inside one LMS is a complete, portable `.h5p` package. Always preview it before publishing.

## Test before sharing

Open the published page in a private/incognito browser window and check:

1. The activity loads and is not stuck on a blank frame.
2. Its interactions, media, and fullscreen button work.
3. The iframe expands far enough to show the entire activity.
4. A large video starts in an acceptable time on a normal connection.
5. The activity works for a visitor who is not signed in to your authoring system.

For a package-level check before publishing, use the open-source verifier:

```bash
npx @missing-elements/h5p-verify course.h5p
```

It opens the package in a real browser runtime and reports missing libraries, startup errors, and a screenshot.

## Privacy and security

### What Embed My isolates, and what it does not

H5P packages contain JavaScript libraries. The player runs those libraries inside the Embed My iframe, on `embed-my.js.org`, rather than on the website where you paste the iframe. A package loaded through Embed My therefore does not run as JavaScript on your portfolio, school-site, or CMS origin, and cannot read that site's cookies or storage. This is especially useful when the embedding site cannot safely host its own H5P player files.

The isolation runs the other way too, with one limit. Browsers give the Embed My frame storage that is separate for each site that embeds it, so what a package does inside the frame stays with your site's embeds. Within that, every package embedded through Embed My on the same site shares one store: a package can read what other packages on that site have extracted there, which is their files and package URLs. Embed only packages you trust, as you would any script.

### What is saved

Nothing between visits. Reloading the page starts the activity over, and answers are not kept anywhere. Embed My stores no learner records.

### What you should still protect

- **Share only packages you are allowed to publish.** An H5P package can include copyrighted media, learner-facing data, and JavaScript libraries.
- **Do not put secret package URLs in an embed.** The package URL appears in the iframe address and can be visible in browser history, page source, server logs, and referrer-related systems. A signed URL that expires keeps working only for visitors whose browser already opened it; new visitors get an error.
- **Use HTTPS.** The page containing the iframe must use HTTPS (or `localhost` during development). The player needs a secure context for its Service Worker.
- **Treat the package host as public.** Anyone who can view the page can discover and request the package URL.
- **Avoid personal data in the package.** Embed My is a player, not a learner-record store.

Embed My should not be used to embed private learner records, passwords, API keys, or confidential course material.

### Cookies and tracking

Embed My is a minimal, public player origin: it has no accounts, serves no advertising, and sets no application cookies. The embedding website controls its own privacy notice and any analytics it places around the iframe.

H5P content itself may contact services named by the package, such as YouTube, Vimeo, Google Fonts, MathJax, or an organization-hosted media service. Review a package and its third-party content before publishing it.

## Results, completion, and LMS grades

Embed My displays H5P activities. It does **not** automatically put scores in an LMS gradebook.

H5P activities produce xAPI statements as they are used. Collecting, storing, and sending those statements to an LRS or LMS requires an explicit integration, and the learner's consent where personal data is involved. A standard public embed should be treated as an ungraded activity.

For developers: the frame can hand the statements to the page around it. When the embed address names your page's origin in an `xapi` parameter, the frame posts each statement to that origin by `postMessage`, and to no other; your page checks the message's origin and source and does with them what it will, for example sending them to an LRS. Nothing is sent unless the page asked for it this way.

## Troubleshooting

### The preview says that the package cannot be fetched

Check that:

- the URL is a direct `https://.../*.h5p` URL;
- opening it in a private browser window downloads the package or shows the archive response;
- the file host permits cross-origin browser requests (CORS);
- the URL has not expired and does not require an LMS login.

If you control the file host, allow requests from `https://embed-my.js.org`, since the frame on that origin is what fetches the package, not the page it is embedded in. A permissive public CORS header is often appropriate for publicly shared teaching material:

```text
Access-Control-Allow-Origin: *
```

For large packages, also support ranged requests and expose their headers:

```text
Accept-Ranges: bytes
Access-Control-Expose-Headers: Content-Range, Accept-Ranges, Content-Length
```

With them a large package starts playing after a few kilobytes. Without them it is downloaded whole before the first byte plays, which still works.

### The activity works in my LMS but not in Embed My

The export may not include the H5P libraries it relies on. Re-export a complete package or use an approved library bundle.

### The activity is cut off or leaves blank space

The resizer script line from the generated snippet is missing or was stripped by your site. Use the platform's dedicated **Embed**, **Custom HTML**, or **iframe** block, which usually keeps scripts, or ask the site administrator to permit the script. If scripts cannot be used at all, set the iframe's height to fit the activity.

### A video is slow to start

Large media may be compressed inside the `.h5p` archive or may not be arranged for progressive playback. Ask the package publisher to optimize the archive with:

```bash
npx @missing-elements/h5p-normalize course.h5p
```

This rewrites the package for streaming without changing the learning content.

### The activity does not load in an app's built-in browser

Some in-app browsers give a frame no Service Worker, and the frame shows a link to open the activity on its own page. Share that link, or the page's own URL to open in a regular browser.

### The host blocks the iframe

Some sites have a Content Security Policy that restricts frames. The embedding site must allow:

```text
frame-src https://embed-my.js.org
```

If the site cannot allow an iframe, link directly to the activity's Embed My page instead.

## Accessibility

Embed My provides the iframe container, a descriptive frame title, and fullscreen support; inside the frame the player names the content's frame after the package's own title. The activity's learning controls, keyboard behavior, captions, alternative text, contrast, and reading order are determined by the H5P content type and by the activity author.

Before publishing:

- give the iframe a meaningful title;
- use keyboard navigation to complete the activity;
- provide captions/transcripts for video and audio;
- include text alternatives for meaningful images;
- avoid making an H5P interaction the only way to access essential information.

## PDFs (planned)

Embed My intends to offer PDF embeds built on `pdfjs-viewer-element`, with the same paste-an-iframe workflow:

```html
<iframe
  src="https://embed-my.js.org/pdf?src=https%3A%2F%2Ffiles.example.edu%2Fhandbook.pdf"
  title="Student handbook"
  loading="lazy"
  style="width: 100%; min-height: 700px; border: 0"
></iframe>
```

This example is illustrative only until PDF support is released. PDF files will have similar requirements: a direct public HTTPS URL, CORS access, and no confidential URL data in the query string.

## Get help and suggest improvements

If an activity does not load, include:

- the page URL where it is embedded;
- the package URL, if it is public;
- the browser and version, and whether it is an app's built-in browser;
- a screenshot or the visible error message;
- whether it worked from a local `.h5p` file or inside another platform.

For feature requests and bug reports, open an issue in the relevant [Embed My organization repository](https://github.com/embed-my).
